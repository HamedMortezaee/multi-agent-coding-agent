# Technical Contracts
## Multi-Agent Coding Agent

**Version:** 1.0  
**Status:** Baseline  
**Date:** 2026-10-03

---

# 1. Purpose

This document defines the machine-readable contracts exchanged between:

- n8n
- ASP.NET Core backend
- Planner
- Coder
- Tester / Reviewer
- Fixer
- Reporting components

The primary goals are:

- deterministic integration
- structured LLM outputs
- easier validation
- easier n8n mapping
- stable API evolution

---

# 2. Common Conventions

## 2.1 ExecutionId

Every run has a unique identifier:

```text
executionId: UUID
```

Example:

```json
{
  "executionId": "49fb20b7-8b64-4e26-aaf9-78d99215b419"
}
```

## 2.2 Timestamps

All timestamps use ISO-8601 UTC format.

Example:

```json
{
  "startedAt": "2026-10-03T12:30:00Z"
}
```

## 2.3 Agent Names

Allowed values:

```text
planner
coder
tester
fixer
reporter
```

## 2.4 Run Status

Allowed values:

```text
Created
Planning
WaitingForHuman
Coding
WaitingForExecution
Executing
Reviewing
Fixing
Completed
Failed
TimedOut
```

# 6. Planner Contract

## Input

```json
{
  "executionId": "49fb20b7-8b64-4e26-aaf9-78d99215b419",
  "userRequest": "Create a Todo ASP.NET Core Web API.",
  "context": {
    "targetPlatform": "ASP.NET Core",
    "language": "C#"
  }
}
```

## Output

```json
{
  "goal": "Create a Todo REST API",
  "summary": "A small ASP.NET Core Web API with CRUD operations.",
  "steps": [
    {
      "order": 1,
      "title": "Create project structure",
      "description": "Create the ASP.NET Core Web API project."
    },
    {
      "order": 2,
      "title": "Create Todo model",
      "description": "Add Title, Description and IsCompleted."
    },
    {
      "order": 3,
      "title": "Create CRUD endpoints",
      "description": "Create create/read/update/delete API endpoints."
    },
    {
      "order": 4,
      "title": "Create tests",
      "description": "Create basic API tests."
    }
  ],
  "assumptions": [],
  "ambiguities": [],
  "requiresHumanReview": true,
  "humanReviewReason": "Mandatory MVP approval step"
}
```

## Validation Rules

- `goal` is required.
- At least one step is required.
- `steps[].order` must be unique.
- `requiresHumanReview` is required.
- No source files are generated by Planner.

# 8. Coder Contract

## Input

```json
{
  "executionId": "49fb20b7-8b64-4e26-aaf9-78d99215b419",
  "userRequest": "Create a Todo ASP.NET Core Web API.",
  "approvedPlan": {},
  "humanFeedback": "Add Swagger documentation.",
  "currentFiles": []
}
```

## Output

```json
{
  "projectName": "Todo.Api",
  "files": [
    {
      "path": "Todo.Api/Todo.Api.csproj",
      "content": "<Project Sdk=\"Microsoft.NET.Sdk.Web\">...</Project>",
      "operation": "create"
    },
    {
      "path": "Todo.Api/Program.cs",
      "content": "...",
      "operation": "create"
    }
  ],
  "notes": [
    "Uses in-memory storage for MVP."
  ]
}
```

Allowed operations:

```text
create
update
delete
```

## Validation Rules

- Paths must be relative.
- Paths must not contain `..`.
- Absolute paths are rejected.
- File content must be text for MVP.
- Duplicate paths are rejected.
- Initial Coder output must use operation `create`.
- Coder is instructed to include at least one automated xUnit test project.
- Coder should include a solution containing both API and tests when practical.

# 9. Project File Contract

```json
{
  "path": "Todo.Api/Program.cs",
  "content": "...",
  "operation": "create",
  "version": 1
}
```

Fields:

| Field | Type | Required | Description |
|---|---|---:|---|
| path | string | yes | Relative path |
| content | string | conditional | Required for create/update |
| operation | enum | yes | create/update/delete |
| version | integer | no | Backend-managed version |

```json
{
```


Allowed severity values:

```text
Info
Warning
Error
Critical
```

Allowed nextAction values:

```text
complete

```

# 13. Fixer Contract

## Input

```json
{
  "executionId": "49fb20b7-8b64-4e26-aaf9-78d99215b419",
  "approvedPlan": {},
  "currentFiles": [],
  "latestReview": {},
  "latestExecutionResult": {},
  "previousAttempts": [],
  "fixAttemptNumber": 1
}
```

## Output

```json
{
  "changes": [
    {
      "path": "Todo.Api/Program.cs",
      "operation": "update",
      "content": "...",
      "reason": "Add the missing namespace reference."
    }
  ],
  "summary": "Applied one fix for the compilation error."
}
```

## Rules

- Fixer must receive previous attempts.
- Fixer must not silently change the approved product scope.
- Fixer should explain every change.
- Maximum fix attempt number is 3.

# 18. n8n Mapping Principles

n8n nodes should pass `executionId` through every branch.

No workflow step should depend on in-memory data from a previous node if that data is also persisted in backend state.

Recommended pattern:

```text
n8n
  ↓
Call Backend
  ↓
Receive structured response
  ↓
Route by explicit field
```

Examples:

```text
requiresHumanReview == true

nextAction == "fix"

fixAttemptCount < 3

status == "Completed"
```

---

# 19. Versioning

Contracts are versioned independently from application deployment.

Initial version:

```text
v1
```

Future breaking API changes should use:

```text
/api/v2/...
```

rather than silently changing v1 semantics.

# 20. Runner Execution Contract

Agent API sends the current project snapshot to CodingAgent.Runner.

Request shape:

```json
{
  "executionId": "49fb20b7-8b64-4e26-aaf9-78d99215b419",
  "files": [
    {
      "path": "TodoApi/Program.cs",
      "content": "..."
    }
  ],
  "command": "dotnet test",
  "timeoutSeconds": 120
}
```

Allowed command values:

```text
dotnet restore
dotnet build
dotnet test
```

For `dotnet test`, Runner resolves a solution or test project before execution.
